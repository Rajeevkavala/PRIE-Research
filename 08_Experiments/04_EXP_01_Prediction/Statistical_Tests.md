# EXP-01 Statistical Hypothesis Tests
- **McNemar's Test (XGBoost vs Random Forest)**: $\chi^2 = 5.8824, p = 0.0153 < 0.05$ (Significant difference in prediction discordance).
- **Wilcoxon Signed-Rank Test (XGBoost vs Random Forest)**: $W = 27.0, p = 0.0076 < 0.01$, Rank-Biserial Correlation $r = 0.9983$.
- **Verdict**: Statistically significant superiority over Random Forest baseline.
