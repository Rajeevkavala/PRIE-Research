# Dataset Protocol: DS-BENCH-02 (OULAD Longitudinal Telemetry)
- **Identifier**: `DS-BENCH-02`
- **Source**: Open University Learning Analytics Dataset (Kuzilek et al.)
- **Sample Size**: $N = 32,593$ student registrations across 22 module presentations.
- **Features**: Daily Virtual Learning Environment (VLE) interaction clickstreams across 20 activity types.
- **Target Variable**: Student outcome tier (`final_result` $\in$ Distinction, Pass, Fail, Withdrawn).
- **Epistemological Role**: Multi-horizon temporal sequence forecasting benchmark (`EXP-3` in Phase 06).
