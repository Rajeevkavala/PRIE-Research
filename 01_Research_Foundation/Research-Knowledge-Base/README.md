# ScholarCamp Research Knowledge Base

## Scope and evidence policy

This knowledge base is derived from `ScholarCamp AI Literature Review Plan.md`, which is a **secondary literature-review plan**, not a single full-text paper. It contains five detailed paper profiles and a cross-paper synthesis. Accordingly, this repository preserves reported claims, distinguishes synthesis-level inference, and marks unavailable details as **Not reported in the source plan**. It does not invent architecture parameters, experimental protocols, authors, or results.
