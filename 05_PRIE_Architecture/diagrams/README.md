# PRIE Architecture Diagrams Catalog

Welcome to the **PRIE Architecture Visual Asset Catalog**. This directory contains the complete suite of **14 architectural diagrams** for the Placement Readiness Intelligence Engine (PRIE), fully exported and formatted across **6 industry-standard formats**:

1. **Markdown Documents (`.md`)**: Full documentation with embedded Mermaid and explanations.
2. **Normal Mermaid Code (`.mmd`)**: Raw Mermaid definitions in [`mermaid/`](file:///d:/4-1%20AD/All%20College%20Docs%20and%20ppts/Documentations/PDR/PRIE-Research/05_PRIE_Architecture/diagrams/mermaid).
3. **Scalable Vector Graphics (`.svg`)**: Infinite-resolution vector graphics in [`svg/`](file:///d:/4-1%20AD/All%20College%20Docs%20and%20ppts/Documentations/PDR/PRIE-Research/05_PRIE_Architecture/diagrams/svg).
4. **High-Resolution PNGs (`.png`)**: Crisp raster renderings in [`png/`](file:///d:/4-1%20AD/All%20College%20Docs%20and%20ppts/Documentations/PDR/PRIE-Research/05_PRIE_Architecture/diagrams/png).
5. **Portable Document Format (`.pdf`)**: Publication-ready vector/raster PDF files in [`pdf/`](file:///d:/4-1%20AD/All%20College%20Docs%20and%20ppts/Documentations/PDR/PRIE-Research/05_PRIE_Architecture/diagrams/pdf).
6. **Excalidraw Canvases (`.excalidraw`)**: Native whiteboard canvas files in [`excalidraw/`](file:///d:/4-1%20AD/All%20College%20Docs%20and%20ppts/Documentations/PDR/PRIE-Research/05_PRIE_Architecture/diagrams/excalidraw).
7. **Draw.io Diagrams (`.drawio`)**: Diagrams.net XML project files in [`drawio/`](file:///d:/4-1%20AD/All%20College%20Docs%20and%20ppts/Documentations/PDR/PRIE-Research/05_PRIE_Architecture/diagrams/drawio).

## 2. Format Usage Instructions

### A. Excalidraw (`.excalidraw` / `.excalidraw.json`)
- **Direct Web Opening**: Navigate to [https://excalidraw.com](https://excalidraw.com), click the Open/Folder icon, and select any file from `excalidraw/`.
- **VS Code Extension**: Install the `bierner.markdown-mermaid` or `pomdtr.excalidraw-editor` extension in VS Code to view and edit right inside your IDE.
- **Mermaid-to-Excalidraw**: In Excalidraw, click the three-dots menu $\to$ **Insert** $\to$ **Mermaid to Excalidraw**, then paste the code from any `.mmd` file in `mermaid/`.

### B. Draw.io (`.drawio`)
- **Web App**: Open [https://app.diagrams.net](https://app.diagrams.net), select **Open Existing Diagram**, and choose any file from `drawio/`.
- **VS Code Extension**: Install `hediet.vscode-drawio` in VS Code. Simply double-click any `.drawio` file to edit diagrams directly in VS Code.
- **Desktop**: Open with the Draw.io Desktop application on Windows/Mac/Linux.

### C. Scalable Vector Graphics (`.svg`)
- Can be dragged and dropped into Microsoft PowerPoint, Word, Google Slides, Adobe Illustrator, Figma, or any web browser with 100% infinite zoom clarity.

### D. Normal Mermaid (`.mmd`)
- Pure syntax files with no markdown fences. Ready to be pasted into [mermaid.live](https://mermaid.live), Notion, GitHub comments/wikis, Obsidian, or used in automated documentation pipelines (`mmdc`).
