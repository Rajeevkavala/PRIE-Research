## 1. Epistemological Separation: Events vs Features vs Predictions

To maintain scientific rigor in learning analytics (`M11`):
- **Raw Events**: Atomic, immutable interaction logs (e.g., `user_click`, `quiz_attempt`, `video_pause`).
- **Engineered Features**: Mathematical aggregation of event streams over standardized rolling time windows (e.g., `consistency_score`, `engagement_entropy`).
- **Model Predictions**: Inferences generated by machine learning models estimating future readiness or risk.

## 3. Week 3–4 Early-Warning Disengagement Detection (`RO3`, `Paper02`)

Literature demonstrates that student disengagement in Semester 7 placement preparation solidifies within the first 3 to 4 weeks (`Paper02`, `Paper05`). PRIE computes an early-warning risk trigger at Week 4:

$$\text{Risk\_Score}_{\text{W4}}(s) = \sigma\left( \beta_0 + \beta_1 \Delta \text{Logins} + \beta_2 \text{QuizDelay} + \beta_3 \mathcal{H}_{\text{entropy}} \right)$$

### Early Warning Criteria:
If $\text{Risk\_Score}_{\text{W4}} \ge 0.65$:
1. A silent notification is dispatched to the faculty mentor dashboard (`M12`).
2. The recommendation engine adapts the student's roadmap to reduce cognitive friction.
3. Automated RAG support proactively suggests introductory conceptual primers.
