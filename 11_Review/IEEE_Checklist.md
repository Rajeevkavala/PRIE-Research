# IEEE Conference Manuscript Compliance Checklist

- [x] **Title & Abstract:** Title is informative; abstract is under 250 words and summarizes background, methodology, results, and contributions.
- [x] **Keywords:** Includes 6–8 IEEE standard index terms.
- [x] **Structure:** Follows 2-column format with formal section hierarchy (I through XV).
- [x] **Equations:** Formally numbered with standard mathematical formatting.
- [x] **Figures:** Vector SVG graphics prepared with high resolution (>300 DPI) and accessible color palettes.
- [x] **Tables:** Standard booktabs formatting without excessive vertical gridlines.
- [x] **References:** Formatted in IEEE numerical bracketed style ([1], [2]).
